AT+HTTPDATA=16,1000

The AT+HTTPDATA=<length>,<timeout> command tells the GSM module:

<length> → How many bytes of data you’re going to send in the HTTP POST body.

<timeout> → How long (in milliseconds) the module should wait for you to send the data.

Tells the module you want to send 16 bytes of HTTP POST data.

16 = length of data in bytes.

1000 = maximum time in milliseconds (1 second) allowed for you to finish sending the data.

DOWNLOAD

The module responds with DOWNLOAD when it’s ready for you to send the data.
